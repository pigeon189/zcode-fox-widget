# fox-dock 控制台 UI 规格

> 2.0 控制台（`dock/ui/`）的最小维护规格。数值以 `ui/tokens.css` 为准；
> 页面验收用 `npm run test:ui`（布局 + 可访问名称 + axe）。

## 1. 两层结构

| 层 | 载体 | 内容 |
|---|---|---|
| 宠物层 | `overlay` 透明全屏置顶窗，穿透 | 角色、胶囊、气泡、快览卡、菜单；吸附（四角/边缘/窗口内自由位置）/镜像 |

宠物层菜单宽 196px；快览卡只在首次打开、角色移动、换档或视口变化时定位，此后顶部固定、
内容向下伸展并在 480px 上限内滚动；刷新键使用与控制台同款的 SVG 刷新图标（32×32 容器 flex
居中、16px 图标、1.75 线宽）并绝对定位在卡片右上角，不提供「打开会话页」页脚。台词/消耗气泡
候选包含快览卡左右外侧，并强制整只气泡留在视口内。隐藏金额时整个小胶囊隐藏，而不是把金额掩码。
失去吸附（宿主最小化/关闭）时角色回落到「失焦兜底位置」，避免沿用宿主窗口坐标；宿主失前台或
被完全覆盖持续约 0.5 秒时同样落兜底（防抖，避免频繁切窗抖动），回前台后自动恢复吸附，只挪位置不做
z-order 隐身（D041）。兜底角落可选（`fallbackCorner`：右下/左下/右上/左上，默认右下，迁移 1.x
defaultCorner），落在角落时角色面向屏幕内侧（右半角不镜像、左半角镜像），恢复吸附或用户拖动后
回到常规朝向规则。兜底是瞬时显示状态，**不写回 floating.rect**（重载/改设置后按当时
设置重新落角，daemon 只记录用户亲手拖出的位置）。兜底位**直接贴住工作区角落、不留观感间距**：浮层窗口与工作区精确重合
（`overlay/window-bounds.cjs`）；仅当任务栏自动隐藏（工作区==整屏）时窗口四周留 1 DIP 不可见缝，
避免被系统当作全屏窗口压住任务栏滑出热区（1.x v1.16.2 issue #8 的最小化版本）。换角色时新图以 180ms opacity 零延迟淡入（一次性
功能动画，`prefers-reduced-motion` 下关闭）。会话的「工作中/等待确认」按根会话计数，子任务
状态归并到父会话。
| 控制台 | `console` 独立可聚焦窗口 | 总览、会话（上下文并入详情标签）、用量、统计、额度与余额、厂商与密钥、角色与气泡、设置、关于 |

控制台下拉与复选框使用自绘控件（`components/base.mjs` 的 `Select` / `Checkbox`），不使用原生
`<select>` 弹出层；日期筛选同样使用自绘 `DatePicker`，不使用原生 `<input type="date">` 面板。
设置页不因打开控件产生横向滚动或整页位移。

控制台窗口 960×680 起、最小 760×560；关闭收进后台，托盘/热键再次打开走第二实例显示已有窗口。
「退出」始终是本次退出：托盘与宠物菜单的退出项标注「（本次退出）」，不触碰开机自启；开机
自启只由设置页/托盘的独立开关决定（D048）。
渲染层不接触 Node 与 daemon 令牌：所有请求经 preload → 主进程 IPC。

## 2. 设计令牌

- 颜色：`--bg/--surface/--surface-2/--border/--text/--text-2/--text-3`；状态 `--ok/--warn/--bad/--info`；
  强调色 `--accent/--accent-strong`（浅色 `#f0a04b` / `#8a5316`）；焦点 `--focus`。
- 对比度：正文 ≥4.5:1；徽标文字使用 `--ok-strong` 等深色变体，避免 12% 底色下不达标。
- 图表色：`--c1..--c7` 固定顺序（前五个用于缓存构成：缓存命中/未缓存输入/缓存写入/输出/推理；模型占比第 1–6 名用 c1–c6，「其他模型」用 c7），阈值另用虚线 + 百分比文字作第二通道。
- 字号只允许 `12/13/14/16/20/24/32/40`；正文 13，页面标题 20/700，卡片标题 14/600，最小 12。
- 间距 4/8/12/16/24/32；卡片内边距 16、卡片间距 16、页面左右 24；圆角 6/8/12/16/999。
- 状态色 `--st-working/--st-waiting/--st-error/--st-done/--st-idle`；可信度 `--prov-official/local/estimate/unavail-{fg,bg}`；会话行高 `--row-h:48px`。
- 动画 120–200ms（Skeleton 扫描 1.2s 为加载态例外），`prefers-reduced-motion` 下全部关闭。
- 动画红线（D039）：只允许状态存续期间的功能性动画 `fd-spin`（working 旋转弧）与权限到达一次性 `fd-nudge`；空闲场景 `document.getAnimations()` 的无限动画为 0。

## 3. 语义结构

- 侧栏 208px（<860px 收成 56px 图标栏）；分组「监控 / 管理」，底部状态 + 关于。导航固定 9 项：总览、会话、用量、统计、额度与余额、厂商与密钥、角色与气泡、设置、关于；「上下文」不再是独立页。
- 页头 72px：H1、按宿主取数的页面显示视角分段（跟随吸附 + 四个 agent）、刷新；总览/用量/厂商/角色/设置/关于不显示；<1100px 隐藏「上次更新」。
- 内容区 12 栏栅格、可键盘聚焦滚动；所有页面无横向滚动、无元素溢出。
- 每个页面有 `data-testid="page.<name>"`，导航有 `nav.<name>`，图表/关键卡片有稳定 testid。

## 4. 组件约定

Button（primary/secondary/ghost/danger，32 高）、IconButton（32×32，必须有 `aria-label`）、
Card、Badge（ok/warn/bad/info/neutral）、Toggle（绑定 label 或 `ariaLabel`）、
Input/Select（必须有可访问名称）、DatePicker、SearchBox、Segmented（`role=tablist`）、ProgressBar（`role=progressbar`）、
Gauge、StackedBar、AreaChart、ColumnChart、EmptyState、Toast、Dialog、Skeleton。

DatePicker 弹层为 `role=dialog` + `aria-modal`，`aria-activedescendant` 挂在持有焦点的弹层上；
方向键/Home/End/PageUp/PageDown/Enter/Esc 可用，`min`/`max` 之外不可选，Tab 与 Esc 关闭后焦点
回到触发按钮。

图表必须有 `role="img"` 与 `aria-label`；纯装饰图标 `aria-hidden`。

## 5. 页面要点

- **总览**：预警条在页头下方；四块任务卡（今日成本含环比 + 7 日 Sparkline、当前会话含状态/运行时长/上下文、待处理、预警）；近 7 天成本 + 额度窗口；厂商余额；全部 Agent 今日（状态列用会话聚合状态）。首屏必须可见今日成本、当前会话、待处理数、预警数。今日成本卡的趋势图固定 90px 高、贴卡片底部并拉伸到卡片内容宽度；预付/套餐口径只切换标题与数字，不再附加「预付/套餐不计金额」说明。近 7 天成本与用量页共用同一份按日汇总（`/v1/usage/breakdown` 的 `daily`），预付/套餐日按等价市值显示并在 tooltip 标注「含预付等价」，避免账本只记录 0 时图表出现空条。
- **会话**：状态计数条（可点击筛选，working 计数 >0 时旋转弧）；列表（搜索/状态/排序/归档筛选、25 条一页 + 加载更多、父任务折叠、子任务缩进、↑↓/Enter/Home/End）；详情（概览 2×2 Stat + StatusTimeline + 最近错误、回合、工具、上下文、跳转宿主窗口）。宽度 ≥1180px 时列表与详情并排，960 默认窗口改为列表占满宽度、详情下移的单列布局，标题列保留至少约 350px。`#context` 与旧 localStorage 页码重定向到 `#sessions?tab=context`。
- **用量**：今日/7 天/30 天/自定义（自绘 DatePicker，非法区间不发请求）+ 金额/Token + 币种 + 对比上一周期；四块磁贴（总成本/总 Token/日均/本月预测）；StackedColumnChart/ColumnChart（对比虚线）；下钻按 Agent/模型/厂商/工具/会话 + 排名 + 明细；明细搜索支持维度名/日期/时间。时间只过滤明细，图表、磁贴、合计与导出始终使用完整聚合口径（包括 WorkBuddy/dsh 没有 `aggregateUsage` 的退路）。CSV/JSON 导出（BOM、公式注入防护）。
- **统计**：区间含自绘 DatePicker；5 个磁贴与 quality chips 带 `SourceTag`；Kimi 显示「只提供套餐窗口」空态。Token 活动为 53 周绿墙，支持每日/每周/累计；悬停明细显示在点阵上方的常驻读数条（`stats.heatmapReadout`），不覆盖点阵，日期与「当周/当周累计」不拆行。
- **额度与余额**：卡片｜矩阵两种视图；矩阵列 = 厂商/余额/5 小时窗/周窗/月窗/重置于/来源；窄屏只允许矩阵容器内横向滚动。厂商卡支持余额校正。余额卡与厂商卡展示 `balanceSplit` 的「充值/赠送」构成，缺失一侧隐藏，人工校正后隐藏构成行。百分比统一 0–100 口径（一位小数），且必须来自同一条目的剩余/总额，总额不可得时不显示百分比、不补 0（D046）。火山方舟（Coding/Agent Plan）为订阅窗口卡：最紧窗口剩余为主数值，Coding·5 小时/周/月与 Agent·近一天/周/月分别成窗，凭据未配置或查询失败时如实显示原因，不显示虚假满额（D047）。
- **厂商与密钥**：默认筛选「已配置」，无已配置项时回落「全部」，并可用「全部」切换；已配置项优先排序。掩码状态、配置/测试/删除、从宿主导入；密钥框默认 password，可显隐。`kind:'tokens'` 模板只表示「仅凭据 / 仅计价」，明确标注没有余额接口，不显示伪造的可用余额。火山方舟订阅配额的凭据是火山 IAM AK/SK 成对配置（两个带可访问名称的输入框，成对保存/删除），模型调用的 ark- key 不用于配额查询（D047）。
- **角色与气泡**：六内置 + 导入（PNG/GIF 校验、删除）、强调色、气泡开关/停留/台词间隔、模板 JSON。手动选角同时关闭「按模型换角色」。
- **设置**：搜索 + 分组；改动立即 PUT，失败回滚并 Toast；每行标签在左、控件在右。「按模型换角色」开关与「今日预算」的金额/积分两个输入框在此页。「开机自启」行说明退出只是本次退出、不影响本开关（D048）。
- **关于**：版本/运行信息/适配器/绑定、检查更新、复制/导出诊断包（均要有 Toast 反馈）。

## 6. 验收清单

- 9 页 × 浅/深主题 × 1280/960/760：无 JS 异常、无横向滚动、字号 ≥12、交互元素有可访问名称、axe 严重/致命 0。
- 默认 960×680 下会话列表与详情为单列，标题列不被固定列挤没；列表滚动与「加载更多」不改变已有 `scrollTop`。
- 日期筛选全部为自绘 DatePicker；弹层在 760 宽内不越出视口，键盘可选日期，关闭后焦点回到触发按钮。
- 统计热力图切到每周/累计时，悬停读数条不覆盖点阵；日期与「当周/当周累计」不换行。
- 厂商页默认「已配置」；无已配置项时回落「全部」，`kind:'tokens'` 明确标注仅凭据/仅计价。
- 总览首屏可见今日成本/当前会话/待处理/预警；上下文不可得时显示 EmptyState 而不是空白。
- 会话行 `.sess-row` 48px（子行 40）、表头 36、计数磁贴 56（<1100 为 48）；`SourceTag.full` 20、dot 16×16；非省略节点不溢出。
- 所有弹窗可用键盘关闭（Esc），焦点有可见环；关闭后回到触发按钮。
- 数字列右对齐、单位紧贴数字；多币种/积分不混算。
- 截图矩阵：`npm run shots -- --page console --console-pages <pages> --theme light,dark --base <fixture>`。
- 场景视觉矩阵：`npm run visual` 共 128 张 = 9 页 × 双主题 × 两视口（36）+ 92 张 pre.2 场景（sessions-live/empty/kimi-only/many/long-text、permission-*、usage-*、quota-matrix、stats-*、settings-live-perm、about-ingest-diag、sourcetag-gallery、provenance-all-kinds）。
