# fox-dock 控制台 UI 规格

> 2.0 控制台（`dock/ui/`）的最小维护规格。数值以 `ui/tokens.css` 为准；
> 页面验收用 `npm run test:ui`（布局 + 可访问名称 + axe）。

## 1. 两层结构

| 层 | 载体 | 内容 |
|---|---|---|
| 宠物层 | `overlay` 透明全屏置顶窗，穿透 | 角色、胶囊、气泡、快览卡、菜单；吸附（四角/边缘/窗口内自由位置）/镜像 |

宠物层菜单宽 196px；快览卡只在首次打开、角色移动、换档或视口变化时定位，此后顶部固定、
内容向下伸展并在 560px 上限内滚动（超限才内部滚动）；刷新键使用与控制台同款的 SVG 刷新图标
（32×32 容器 flex 居中、16px 图标、1.75 线宽）并绝对定位在卡片右上角，不提供「打开会话页」
页脚。台词/消耗气泡候选包含快览卡左右外侧，并强制整只气泡留在视口内；候选同分时按「与角色
距离」打破平局，贴角场景不得为了避开卡片把气泡甩到卡片外侧。隐藏金额时整个小胶囊隐藏，
而不是把金额掩码。
快览卡的额度窗口行之后可追加按模型分桶行（最多 3 条，标签列 80px 省略、完整名走 title，
尾列显示「剩余/总量」tokens；填充同样是已用比例，D053）。
「避让滚动条」（`scrollGapOn`/`scrollGap`，默认 17px）只作用于右边：吸附宿主时按宿主窗口
右缘留缝，桌面悬浮时按屏幕（工作区）右缘留缝；底/顶/左边始终贴死（1.x 同款）。开关改变时
桌面悬浮的角色立即重新夹取位置，从开切到关且正停在「右缘−旧缝」上时贴回屏幕右缘。
快览卡的锚点高度按真实内容高度（`scrollHeight` + 边框）预留，最大高度 560px；异步内容
（会话/额度窗口/时段）晚到时只要出现滚动条就把卡片上移（只上不下，没有溢出不动，
不再受 1.5 秒窗口限制）。CommandCode「余额 + 3 个额度窗口 + 3 条会话」的常规内容
在 960×680 与 DPR 1.25 下都必须一次放得下，不出现纵横滚动条；窗口/上下文/会话行
间距保持紧凑（4/8/10px）。
失去吸附（宿主最小化/关闭）时角色回落到「失焦兜底位置」，避免沿用宿主窗口坐标；宿主失前台或
被完全覆盖持续约 0.5 秒时同样落兜底（防抖，避免频繁切窗抖动），回前台后自动恢复吸附，只挪位置不做
z-order 隐身（D041）。兜底角落可选（`fallbackCorner`：右下/左下/右上/左上，默认右下，迁移 1.x
defaultCorner），落在角落时角色面向屏幕内侧（右半角不镜像、左半角镜像），恢复吸附或用户拖动后
回到常规朝向规则。兜底是瞬时显示状态，**不写回 floating.rect**（重载/改设置后按当时
设置重新落角，daemon 只记录用户亲手拖出的位置）。兜底位**直接贴住工作区角落、不留观感间距**：浮层窗口与工作区精确重合
（`overlay/window-bounds.cjs`）；仅当任务栏自动隐藏（工作区==整屏）时窗口四周留 1 DIP 不可见缝，
避免被系统当作全屏窗口压住任务栏滑出热区（1.x v1.16.2 issue #8 的最小化版本）。换角色时新图以 180ms opacity 零延迟淡入（一次性
功能动画，`prefers-reduced-motion` 下关闭）。会话的「工作中/等待确认」按根会话计数，子任务
状态归并到父会话。
| 控制台 | `console` 独立可聚焦窗口 | 总览、会话（上下文并入详情标签）、用量、统计、额度与余额、厂商与密钥、角色与气泡、设置、关于 |

控制台下拉与复选框使用自绘控件（`components/base.mjs` 的 `Select` / `Checkbox`），不使用原生
`<select>` 弹出层；日期筛选同样使用自绘 `DatePicker`，不使用原生 `<input type="date">` 面板。
设置页不因打开控件产生横向滚动或整页位移。

控制台窗口 960×680 起、最小 760×560；关闭收进后台，托盘/热键再次打开走第二实例显示已有窗口。
「退出」始终是本次退出：托盘与宠物菜单的退出项标注「（本次退出）」，不触碰开机自启；开机
自启只由设置页/托盘的独立开关决定（D048）。
页面渲染异常由错误边界兜成「重新渲染 / 重新加载控制台 / 复制错误」卡片，侧栏与其它页面
保持可用；渲染进程崩溃/无响应自动退避重载并写 `console-crash.log`（D055）。
控制台是定高壳层：**document 永远不能纵向滚动**，滚动只发生在 `.content`（和矮窗口下的
`.sidebar`）内部；`.content` 必须同时是定位祖先（`position: relative` + `min-height: 0`），
否则页面里的绝对定位控件会锚到初始包含块、把 document 撑高，聚焦控件时整页被滚上去
（`ui-check` 对 9 页 × 2 主题 × 3 视口断言 document 无纵向滚动）。
渲染层不接触 Node 与 daemon 令牌：所有请求经 preload → 主进程 IPC。

## 2. 设计令牌

- 颜色：`--bg/--surface/--surface-2/--border/--text/--text-2/--text-3`；状态 `--ok/--warn/--bad/--info`；
  强调色 `--accent/--accent-strong`（浅色 `#f0a04b` / `#8a5316`）；焦点 `--focus`。
- 对比度：正文 ≥4.5:1；徽标文字使用 `--ok-strong` 等深色变体，避免 12% 底色下不达标。
- 图表色：`--c1..--c7` 固定顺序（前五个用于缓存构成：缓存命中/未缓存输入/缓存写入/输出/推理；模型占比第 1–6 名用 c1–c6，「其他模型」用 c7），阈值另用虚线 + 百分比文字作第二通道。
- 字号只允许 `12/13/14/16/20/24/32/40`；正文 13，页面标题 20/700，卡片标题 14/600，最小 12。
- 间距 4/8/12/16/24/32；卡片内边距 16、卡片间距 16、页面左右 24；圆角 6/8/12/16/999。
- 状态色 `--st-working/--st-waiting/--st-error/--st-done/--st-idle`；可信度 `--prov-official/local/estimate/unavail-{fg,bg}`；会话行高 `--row-h:48px`。
- 动画 120–200ms（Skeleton 扫描 1.2s 为加载态例外），`prefers-reduced-motion` 下全部关闭。
- 动画红线（D039）：只允许状态存续期间的功能性动画 `fd-spin`（working 旋转弧）与权限到达一次性 `fd-nudge`；空闲场景 `document.getAnimations()` 的无限动画为 0。

## 3. 语义结构

- 侧栏 208px（<860px 收成 56px 图标栏）；分组「监控 / 管理」，底部状态 + 关于。导航固定 9 项：总览、会话、用量、统计、额度与余额、厂商与密钥、角色与气泡、设置、关于；「上下文」不再是独立页。
- 页头 72px：H1、按宿主取数的页面显示视角分段（跟随吸附 + 四个 agent）、刷新；总览/用量/厂商/角色/设置/关于不显示；<1100px 隐藏「上次更新」。
- 内容区 12 栏栅格、可键盘聚焦滚动；所有页面无横向滚动、无元素溢出。
- 每个页面有 `data-testid="page.<name>"`，导航有 `nav.<name>`，图表/关键卡片有稳定 testid。

## 4. 组件约定

Button（primary/secondary/ghost/danger，32 高）、IconButton（32×32，必须有 `aria-label`）、
Card、Badge（ok/warn/bad/info/neutral）、Toggle（绑定 label 或 `ariaLabel`）、
Input/Select（必须有可访问名称）、DatePicker、SearchBox、Segmented（`role=tablist`）、ProgressBar（`role=progressbar`）、
Gauge、StackedBar、AreaChart、ColumnChart、EmptyState、Toast、Dialog、Skeleton。

DatePicker 弹层为 `role=dialog` + `aria-modal`，`aria-activedescendant` 挂在持有焦点的弹层上；
方向键/Home/End/PageUp/PageDown/Enter/Esc 可用，`min`/`max` 之外不可选，Tab 与 Esc 关闭后焦点
回到触发按钮。

图表必须有 `role="img"` 与 `aria-label`；纯装饰图标 `aria-hidden`。

## 5. 页面要点

- **总览**：预警条在页头下方；四块任务卡（今日成本含环比 + 7 日 Sparkline、当前会话含状态/运行时长/上下文、待处理、预警）；近 7 天成本 + 额度窗口；厂商余额；全部 Agent 今日（状态列用会话聚合状态）。首屏必须可见今日成本、当前会话、待处理数、预警数。当前会话卡：标题与标题行留 10px，上下文进度条 + 百分比 + 「查看会话」在同一行；空态在任务卡剩余空间内垂直居中（与标题行留 8px），图表高度监听窗口 resize 即时重算；今日迷你图的高度由组件 prop 与 CSS 同步（窄窗口 56px），避免 viewBox 等比缩放导致左右留白。今日成本卡的趋势图固定 90px 高、贴卡片底部并拉伸到卡片内容宽度；预付/套餐口径只切换标题与数字，不再附加「预付/套餐不计金额」说明。窗口宽度 ≤1279px 时四张任务卡变两列：空态压到 56px（图标 20px）、任务卡内边距 12px、今日迷你图 56px（组件 prop 与 CSS 同值）、7 天柱图 148px，预警条在 `.grid` 里不再叠加额外的 16px 下边距，额度窗口/近 7 天成本两卡的自身空态压到 16px 内边距，保证「四张卡 + 近 7 天成本 + 额度窗口」在默认 960×680 窗口首屏内完整可见（预警条同屏时也成立）。近 7 天成本与用量页共用同一份按日汇总（`/v1/usage/breakdown` 的 `daily`），预付/套餐日按等价市值显示并在 tooltip 标注「含预付等价」，避免账本只记录 0 时图表出现空条。
- **会话**：状态计数条（可点击筛选，working 计数 >0 时旋转弧）；列表（搜索/状态/排序/归档筛选、25 条一页 + 加载更多、父任务折叠、子任务缩进、↑↓/Enter/Home/End）；详情（概览 2×2 Stat + StatusTimeline + 最近错误、回合、工具、上下文、跳转宿主窗口）。宽度 ≥1180px 时列表与详情并排，960 默认窗口改为列表占满宽度、详情下移的单列布局，标题列保留至少约 350px。`#context` 与旧 localStorage 页码重定向到 `#sessions?tab=context`。成本列（112px，回合表 108px）只含真金白银：预付池/套餐行金额记 0、tokens 照算；整段都是预付用量时显示「≈¥x」等价市值并挂 tooltip 说明不是真实支出（D054）。并排布局的窄详情栏（约 288px 内容宽）放不下 6 列固定宽回合表：容器 <420px 时回合表隐藏「开始 / 耗时」两列（序号单元格 `title` 仍给出这两项），成本和状态列不得被裁；<1180px 详情转整宽单列时恢复完整 6 列。状态列/计数/筛选统一用服务端 `displayStatus`（D056）：回合结束后 5 分钟内保持「已完成」，父会话有子任务或 workflow 在跑、或钩子确认回合仍在进行时显示「工作中」；手动停止（`cancelled`）立刻回「空闲」且不进入「已完成」窗口；UI 不得自行按 `status==='done'` 推断，也不得让机器状态里的旧 `working` 盖过已判定的空闲。总览「当前会话」与待处理数同口径：选人读 `displayStatus`，待处理数取服务端全局 `waiting_permission` 计数。
- **用量**：今日/7 天/30 天/自定义（自绘 DatePicker，非法区间不发请求）+ 金额/Token + 币种 + 对比上一周期；四块磁贴（总成本/总 Token/日均/本月预测）；StackedColumnChart/ColumnChart（对比虚线）；下钻按 Agent/模型/厂商/工具/会话 + 排名 + 明细；明细搜索支持维度名/日期/时间。时间只过滤明细，图表、磁贴与合计始终使用完整聚合口径；普通关键词过滤排名、明细与导出（导出口径随当前筛选变化，避免界面所见与导出内容对不上）。CSV/JSON 导出（BOM、公式注入防护）。金额缺失（价目未收录等 `null + unavailable`）在磁贴/排名/明细里显示「—」而不是 ¥0.00；CSV 金额列导出空单元格、JSON 保留 `null`（真实 0 仍写 0）。
- **统计**：区间含自绘 DatePicker；5 个磁贴与 quality chips 带 `SourceTag`；Kimi 显示「只提供套餐窗口」空态。Token 活动为 53 周绿墙，支持每日/每周/累计；悬停明细显示在点阵上方的常驻读数条（`stats.heatmapReadout`），不覆盖点阵，日期与「当周/当周累计」不拆行。工具条左侧宿主标签占固定 208px（截断 + title），日期段控件位置不随宿主名长短移动；刷新只用页头图标按钮，工具条里不重复放「刷新」。
- **额度与余额**：卡片｜矩阵两种视图；矩阵列 = 厂商/余额/5 小时窗/周窗/月窗/重置于/来源；窄屏只允许矩阵容器内横向滚动。厂商卡支持余额校正。余额卡与厂商卡展示 `balanceSplit` 的「充值/赠送」构成，缺失一侧隐藏，人工校正后隐藏构成行。百分比统一 0–100 口径（一位小数），且必须来自同一条目的剩余/总额，总额不可得时不显示百分比、不补 0（D046）。同一套餐内按模型分桶的配额（GLM start plan 赠送池等）在厂商卡与顶部额度卡里按桶画进度条：名称 + 剩余百分比 + 剩余/总量 + 条（填充为**已用**比例，与 CommandCode 窗口同口径），汇总百分比只作参考；总额不可得的桶不显示（D053）。火山方舟（Coding/Agent Plan）为订阅窗口卡：最紧窗口剩余为主数值，Coding·5 小时/周/月与 Agent·近一天/周/月分别成窗，凭据未配置或查询失败时如实显示原因，不显示虚假满额（D047）。
- **厂商与密钥**：默认筛选「已配置」，无已配置项时回落「全部」，并可用「全部」切换；已配置项优先排序。掩码状态、配置/测试/删除、从宿主导入；密钥框默认 password，可显隐。`kind:'tokens'` 模板只表示「仅凭据 / 仅计价」，明确标注没有余额接口，不显示伪造的可用余额。火山方舟订阅配额的凭据是火山 IAM AK/SK 成对配置（两个带可访问名称的输入框，成对保存/删除），模型调用的 ark- key 不用于配额查询（D047）。
- **角色与气泡**：六内置 + 导入（PNG/GIF 校验、删除）、强调色、气泡开关/停留/台词间隔、模板 JSON。手动选角同时关闭「按模型换角色」。「按压音效」卡片：音效集 Select（内置小黄鸭/嘀嘟/猫娘 + 导入集，稳定 testid `sounds.select`）、音量档位、导入（1–2 个音频，单文件 ≤2MB）与两步删除；宠物菜单「音效」区可直接切换。
- **权限待办（pre.3）**：总览与会话页顶部横幅（`perm.banner`，warn 左边线 + 脱敏预览，深色主题预览用 `--text-2` 保证 ≥4.5:1），按钮只有「去宿主处理」「拒绝」与（takeover 与 allowOnce 都开启且非高风险时的）「允许一次」；待办行允许换行、按钮组整组落到下一行，760×560 最小窗口里三个决策按钮都可达；多个 pending 时「查看全部」Dialog（440px 弹窗，待办行按弹窗内容宽度换行，不写死 560px）。宠物层权限卡（`perm.card`，alertdialog）：高风险挂「高风险」徽标且无「允许一次」；分支 B / takeover 关闭时只有「去宿主处理」「拒绝」；超时显示「已超时，请在宿主窗口处理」4 秒后收起。宠物层只在指针压在卡片上时接管鼠标（`isOverUI` 含 `#perm`），卡片显示期间桌面其余位置继续点击穿透。权限热键「允许」与卡片同口径：只在 takeover + allowOnce 都开启且非高风险时注册。桌面通知只写工具名与处理提示，不带 preview/命令原文。
- **接入向导（pre.3）**：三步 Dialog（检测宿主 → 接入方式 → 完成）；只在未完成 onboarding 且发现宿主/旧数据时首启，「关于」页「接入向导」按钮可重开；不自动写宿主配置。「跳过」只结束向导、不碰开机自启（首启机器 `settings.autoStart` 默认 true 但启动件通常未装，不能因跳过就安装 VBS）；只有「完成」才把第 3 步看到的开关值经 `/v1/maintenance/autostart` 落到启动件（D048）。
- **设置**：搜索 + 分组；改动立即 PUT，失败回滚并 Toast；每行标签在左、控件在右。「按模型换角色」开关与「今日预算」的金额/积分两个输入框在此页。「开机自启」行说明退出只是本次退出、不影响本开关（D048）。
- **关于**：版本/运行信息/适配器/绑定、检查更新、复制/导出诊断包（均要有 Toast 反馈）。

## 6. 验收清单

- 9 页 × 浅/深主题 × 1280/960/760：无 JS 异常、无横向滚动、字号 ≥12、交互元素有可访问名称、axe 严重/致命 0。
- 默认 960×680 下会话列表与详情为单列，标题列不被固定列挤没；列表滚动与「加载更多」不改变已有 `scrollTop`。
- 日期筛选全部为自绘 DatePicker；弹层在 760 宽内不越出视口，键盘可选日期，关闭后焦点回到触发按钮。
