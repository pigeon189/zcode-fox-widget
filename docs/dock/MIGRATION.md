# 从挂件线移植到 fox-dock 的功能

对照 `zcode-fox-widget`（ZCode 线）与 `fox-widget`（WorkBuddy 线）的菜单项，逐项判断
在 fox-dock（多 agent 成本看板）里是否有意义。

## 移植

| 挂件线功能 | dock 里的形态 | 说明 |
|---|---|---|
| 角色立绘 | 设置 → 角色 | 六个内置角色（嘎啦嘛 / 大肥鱼 / GPT娘 / kimi娘 / 小克 / 哈基米），610×610 透明 PNG |
| 台词池 | 点击 / 随机说话 | 每个角色一套原台词（含「挑经句」），换角色同时换台词 |
| 大小（缩放） | 设置 → 大小 | 0.75× / 1× / 1.25× / 1.5×；影响角色与卡片的几何 |
| 每轮消耗提示 + 自动关闭 | 设置 → 每轮消耗气泡（开关 + 秒数） | 绑定后轮询发现「上一轮」变化 → 狐狸头上冒一次气泡 |
| 今日预算 | 设置 → 今日预算（元） | 跨 agent 汇总后判断；超了冒一次提醒，每天一次 |
| 额度预警（quotaPct） | 设置 → 额度预警（剩余低于 %） | 只对能给出 `quota` 的适配器生效 |
| 跟随延迟 | 设置 → 跟随间隔 | 250 / 500 / 1000ms |
| 避让滚动条 | 设置 → 滚动条宽度 | 只在右边留出这段距离（默认 17px）：吸附时按宿主窗口右缘，桌面悬浮时按屏幕右缘；底/顶/左边始终贴死（1.x 同款，导入时 `scrollGapPx` 映射为 `scrollGap`） |
| 显示气泡卡片 | 设置 → 显示数字卡片 | 关掉只剩狐狸 |
| 用量记录 + 搜索 | 明细 → 最近 N 天 + 搜索框 | 按适配器名 / 日期过滤 |
| 关于 / 自检 | 面板「关于」页 | 版本、运行环境、适配器、绑定数、更新记录、日志尾部、复制诊断信息 |
| 主题 | 设置 → 主题 | 跟随系统 / 浅色 / 深色 |
| 按宿主换角色 | 设置 → 自动换角色 + 角色页按宿主指定 | ZCode→嘎啦嘛、WorkBuddy→小克、Kimi Code→kimi 娘、dsh→大肥鱼 |
| 额度卡 | 面板「额度」页 + 总览 | 单窗口数字百分比、多窗口进度条、余额卡、Free 套餐说明 |
| 主数字口径 | 设置 → 主数字 | 自动 / 今日 / 余额 / 额度 |
| 7 天用量 | 总览底部 + 用量页 | 跨 agent 按 adapter 汇总，开关可关 |
| 余额来源 | dsh / Kimi 适配器 | dsh 读宿主已有的 DeepSeek 凭据查余额；Kimi 读宿主 OAuth 的套餐窗口/加油包，不要求用户再填 key |

## 不移植（与 dock 的定位冲突或无素材）

| 挂件线功能 | 原因 |
|---|---|
| 音效 / 音量 / 音效组 | 用户此前明确撤回事件音；这一版只做「看得见」的角色与台词，声音等确认后再谈 |
| 按模型换角色 | 角色本身已移植；「按模型自动换」依赖宿主的模型标识，dock 是跨宿主看板，先做成按宿主自动换 + 手动选择 |
| 桌宠模式 | dock 本身就是铺满工作区的桌面浮层，已经具备 |
| 对账口径 / 峰谷 | ZCode 计价内核（逐字节复用）已按时间判定峰谷，UI 不需要再选 |
| 余额校正 / 充值 | dock 只读宿主已有的余额（dsh 的 DeepSeek key、Kimi 的 OAuth），不做充值/校正；那属于厂商客户端的能力 |
| 隐藏菜单按钮 | dock 没有菜单按钮 |
| 等确认提醒 | dock 是跨宿主看板，收不到各宿主的 hook 事件；这属于宿主插件的能力边界 |

## 数据边界

- 设置存在 `%LOCALAPPDATA%\fox-dock\settings.json`，由 daemon 提供 `GET/PUT /settings`；
  overlay 只读写这一份，不在渲染层另存状态。
- Kimi Code 的 OAuth 凭据由适配器在过期时刷新并原子写回宿主自己的
  `~/.kimi-code/credentials/kimi-code.json`；token 不复制到 dock 配置、不写日志。
  dsh 的凭据与会话日志只读。
- 账本只记「今日累计」（`ledger.json`，保留 30 天），不记逐笔。搜索/历史都基于它。
- 角色只认内置六个：`overlay/roles.js` 里的 id 白名单，设置里的未知 id 一律回落 fox。
  不提供「导入角色」——那会把立绘变成任意文件加载通道，不是这一版要背的复杂度。
- 预算与额度提醒都**不补零**：适配器读不到就当作没有数据，绝不把缺失当 0。
