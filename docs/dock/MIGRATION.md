# 从挂件线移植到 fox-dock 的功能

对照 `zcode-fox-widget`（ZCode 线）与 `fox-widget`（WorkBuddy 线）的菜单项，逐项判断
在 fox-dock（多 agent 成本看板）里是否有意义。

## 移植

| 挂件线功能 | dock 里的形态 | 说明 |
|---|---|---|
| 大小（缩放） | 设置 → 大小 | 0.75× / 1× / 1.25× / 1.5×；影响狐狸与卡片的几何 |
| 每轮消耗提示 + 自动关闭 | 设置 → 每轮消耗气泡（开关 + 秒数） | 绑定后轮询发现「上一轮」变化 → 狐狸头上冒一次气泡 |
| 今日预算 | 设置 → 今日预算（元） | 跨 agent 汇总后判断；超了冒一次提醒，每天一次 |
| 额度预警（quotaPct） | 设置 → 额度预警（剩余低于 %） | 只对能给出 `quota` 的适配器生效 |
| 跟随延迟 | 设置 → 跟随间隔 | 250 / 500 / 1000ms |
| 避让滚动条 | 设置 → 滚动条宽度 | 贴右/下边时留出这段距离（默认 17px），不盖住滚动条 |
| 显示气泡卡片 | 设置 → 显示数字卡片 | 关掉只剩狐狸 |
| 用量记录 + 搜索 | 明细 → 最近 N 天 + 搜索框 | 按适配器名 / 日期过滤 |
| 关于 / 自检 | 明细旁「关于」页 | 版本、运行环境、适配器、绑定数、更新记录、日志尾部、复制诊断信息 |

## 不移植（与 dock 的定位冲突或无素材）

| 挂件线功能 | 原因 |
|---|---|
| 音效 / 音量 / 音效组 | 用户已明确撤回事件音；dock 不带音效素材，且这只解决单机氛围，不属于成本看板 |
| 角色 / 按模型换角色 | 需要成体系的立绘素材。多 agent 场景更合理的是「按适配器换形象」，等有素材再做 |
| 桌宠模式 | dock 本身就是铺满工作区的桌面浮层，已经具备 |
| 对账口径 / 峰谷 | ZCode 计价内核（逐字节复用）已按时间判定峰谷，UI 不需要再选 |
| 余额校正 / 余额构成 | dock 不做余额源（要厂商 key），只展示「已用」；余额属于挂件线的宿主能力 |
| 隐藏菜单按钮 | dock 没有菜单按钮 |
| 等确认提醒 | dock 是跨宿主看板，收不到各宿主的 hook 事件；这属于宿主插件的能力边界 |

## 数据边界

- 设置存在 `%LOCALAPPDATA%\fox-dock\settings.json`，由 daemon 提供 `GET/PUT /settings`；
  overlay 只读写这一份，不在渲染层另存状态。
- 账本只记「今日累计」（`ledger.json`，保留 14 天），不记逐笔。搜索/历史都基于它。
- 预算与额度提醒都**不补零**：适配器读不到就当作没有数据，绝不把缺失当 0。
