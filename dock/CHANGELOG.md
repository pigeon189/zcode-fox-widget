# fox-dock 变更记录

> 2.0 起按通用桌宠产品线维护（tag `dock-v*`）。接口、数据格式、适配器契约仍可能变。

## 2.0.0-pre.2（2026-10-20）

从「多 agent 成本看板」升级为通用桌宠：一只角色同时认识 ZCode、WorkBuddy、Kimi Code 与 DeepSeek Harness，拖到哪个窗口就切到哪个宿主的角色、余额与额度口径。

### 修复（相对已撤回的 2.0.0-pre.1）

- **吸附恢复**：最上层判定跳过 TabTip / Windows 输入体验 / NVIDIA 等输入法与驱动辅助窗，不再被它们挡住宿主；只吸附四个宿主 exe。
- **菜单贴底自适应**：右键菜单按最终高度限高并重排，角色在屏幕下方时不再有菜单项越出屏幕；角色图片延迟加载也会重新夹住。
- **音效单轨**：按下/松开共用一个播放通道，快速点击只播按下音，不再两个音同时响。
- **上下文页会话选择**改用自绘下拉；用量页零值不再画 1px 假柱，并为预付池金额 0 增加口径提示。

### 新增

- **独立控制台窗口**：总览、上下文、用量、额度与余额、厂商与密钥、角色与气泡、设置、关于与诊断八页；可缩放、可键盘导航，关闭后仍在后台，托盘/热键可再次打开。
- **宠物层重做**：角色 + 状态胶囊（宿主、主数字、上下文迷你环）+ 320px 快览卡 + 右键菜单；吸附位置与旧挂件一致（四角/边缘/窗口内自由位置）；贴左镜像、拖到桌面进入悬浮并保留上一个 agent 的设置；气泡/台词可点击并推进按压队列。
- **单开关吸附**：右键菜单与设置里只有一个「吸附到 agent 窗口」；关闭后角色留在桌面，不再提供「解除吸附/重置」等重复入口。
- **当前厂商余额**：按最近一次真实调用的 provider 自动选择余额/套餐（CommandCode 显示月度池 + 5 小时/周窗口），总览新增「厂商余额」卡并列展示所有已配置厂商；没有 `ZCODE_DATA_BASE_DIR` 时也能从旧挂件/自身记录找到 ZCode 数据目录。
- **上下文统计**：四宿主读取当前会话占用、上限、请求构成、趋势与压缩记录；读不到就显示「暂无」，不补 0；达到阈值会提醒压缩。
- **厂商引擎内置**：45 个厂商/订阅/中转站模板不再依赖旧挂件服务；DeepSeek 余额、GLM Plan、CommandCode、Kimi/MiniMax/OpenCode 订阅与 10 家中转站都在 dock 内取数。
- **凭据保险库**：API Key 用 Windows DPAPI 加密保存在本机，界面只显示掩码；支持从 ZCode / WorkBuddy 已配置的凭据一次性导入。
- **`/v1` API 与 SSE**：控制台与宿主扩展走版本化接口，状态变化实时推送；写接口需要本机令牌，读接口校验环回 Host。
- **`fox-dock ensure`**：宿主启动时幂等拉起 daemon；已在线时快速返回，不重复启动。
- **自管 Electron 运行时**：优先使用自己安装的版本，缺失时从镜像链下载并校验 sha256；也可继续复用已安装的挂件运行时。
- **托盘与全局热键**：打开控制台、显示/隐藏角色、吸附到 agent 窗口、隐藏金额、开机自启、退出；默认 `Ctrl+Alt+D/F/H`。
- **三态吸附**：拖到桌面空白不再丢失设置，进入「悬浮」状态并沿用上一个 agent 的角色与气泡配置；窗口关闭也是悬浮。
- 用量页支持今日/7 天/30 天、金额/Token、按 agent 排名、搜索与 CSV/JSON 导出；账本开始记录 token 维度。
- 角色大小、隐藏金额（同时不弹消耗气泡）、勿扰（气泡与音效一起静音）、今日/周/月预算、余额与上下文预警、成本异常提醒。
- **角色导入/删除**：PNG / GIF 签名校验（PNG 逐块 CRC）、≤3MB、≤2048²、id 白名单；JPEG/WebP 在控制台内转成 PNG 再导入，GIF 保留动画；内置角色不可删改。
- **余额校正**：充值/赠金、到账扣减、手动设为某值；只记录人工修正，展示时作用在当前余额上。
- **按压泡泡队列**：最多 12 步，点击角色气泡按顺序推进；可在控制台导入或编辑 JSON。
- **按压音效**：内置小黄鸭音效，随「勿扰」静音；快速连击不会叠音。
- **从旧挂件导入**：角色、气泡模板/队列、账本、外观与提醒、厂商 key 引用与中转站令牌，只读源目录。
- **与旧挂件共存**：ZCode / WorkBuddy 插件在 dock 在线时让出浮层，启动时顺手 ensure dock，并把轮开始/等确认事件转发给它。

### 变更

- **角色导入持久化**：导入角色（含 GIF）可以写入档案并立即在浮层生效；设置层接受安全导入 id，非法 id 仍回落内置角色。
- **数据目录统一**：`FOX_DOCK_DATA` 按完整数据目录解释，daemon 在引擎静态求值前解析 `--data-dir`；无 `ZCODE_DATA_BASE_DIR` 时也能从自身 `runtime-env.json` 找到 ZCode 数据目录。
- **CommandCode 套餐额度（2026-10-20）**：GOAT 月度 credits 新账户为 $80；2026-10-20 前创建的订阅保留 $70，额度卡会标注「老账户」；本地池/缺少创建时间时默认按新 80 档。
- **价目复核（2026-10-20）**：Anthropic / Kimi / DeepSeek 在售清单与单价与现表一致；补充 `gpt-daybreak-*` 与 `claude-mythos-preview` 同价别名；MiMo v2.5 系列按官方计划于 2026-10-21 下线，过渡期保留。
- 设置文件升级到 schema 2：全局默认 + 每个 agent 一份档案；旧设置自动备份为 `settings.json.v1.bak`。
- 主题的「跟随 ZCode」改为「跟随系统」；浮层菜单按钮可设为悬停显示/始终显示/隐藏。
- 厂商密钥不再从挂件线服务读取作为主路径；旧配置只作为导入源。

### 安全

- 控制台窗口开启 `contextIsolation` 与 `sandbox`，渲染层拿不到 Node 与 daemon 令牌。
- 保险库密文带明文摘要校验，文件被篡改会明确报错；日志、接口与诊断包扫描密钥模式。
- 角色图片与更新包继续走白名单/魔数/大小校验，拒绝路径穿越与私网出站。

### 四个宿主

- **ZCode**：今日金额 / 上一轮 / tokens 与调用次数，角色默认嘎啦嘛。
- **WorkBuddy**：订阅积分口径，角色默认小克。
- **Kimi Code**：读宿主自己的 OAuth 凭据，过期自动刷新并写回；有套餐窗口时显示 5 小时 / 7 天 / 本月 / 本月 Code 的百分比，Free 账号明确显示「没有可读的套餐额度窗口」，不编 0%。角色默认 kimi 娘。
- **DeepSeek Harness（dsh）**：DeepSeek 开放平台余额 + 会话日志里的今日/上一轮 token 用量；多帧 zstd 会话逐帧解压，上一轮优先主会话而不是 subagent。角色默认大肥鱼。
- 窗口识别按 exe 基名，标题里的项目名变化不会让适配器失效；一个宿主开多个窗口时逐个列出。

### 界面

- 浮层面板重做：总览 / 额度 / 用量 / 角色 / 设置 / 关于六个页签。
- 总览：角色头像 + 宿主名 + 今日/上一轮/余额三格 + 通用额度卡（余额卡、单窗口数字、多窗口进度条、Free 套餐卡）+ 账户与明细。
- 吸附后自动换角色与强调色；「角色」页可以按宿主单独指定角色，也可以随时让角色说一句。
- 主题跟随系统 / 浅色 / 深色；主数字可选自动 / 今日 / 余额 / 额度；7 天用量、搜索、绑定管理都保留。
- **「厂商」页**：复用同机 ZCode / WorkBuddy 挂件线的成熟余额服务，显示全厂商余额与套餐
  （DeepSeek 余额、GLM Plan 配额、CommandCode 三重额度、Kimi/MiniMax/OpenCode 订阅窗口、
  OpenRouter/Moonshot 余额，以及未配置模板）。只读本机接口，凭据不进入 dock。
  ZCode 的今日明细也按厂商拆分，不再只有一个总金额。
- 角色尺寸与旧挂件同口径：100% = 旧版默认档（`min(250px, min(100vw,100vh) * 0.28) * 1.5 * 0.5945`），其余档位等比；静态立绘，不做呼吸缩放。
- 角色右上角菜单按钮（⋯）打开菜单；吸附/脱离不再拆成多个入口，统一为「吸附到 agent 窗口」。
- 控制台的下拉与复选框改为自绘控件，弹出层不再撑宽/滚动设置页；控制台窗口使用 fox-dock 图标，渲染进程崩溃/被遮挡冻结时自动重载。
- 设置里新增「更新清单地址 / 启动时检查」；「关于」页可以手动检查更新。签名清单校验、
  sha256 与回滚沿用现有 CLI 更新器。

### 修复

- 鼠标交互：左键点角色打开/收起面板并说一句；右键不再误开面板或换台词；数字卡片也能点开面板，不再把点击穿透给宿主。
- 面板会避开角色所在的一侧，并在可用高度内滚动，不再一打开就把角色盖住。
- 窗口比屏幕宽时，吸附坐标会被钳在浮层内，角色不再贴着右边缘消失。
- 上一轮金额小于 1 分时保留 4 位小数，不再显示成 ¥0.00。
- 厂商页的 CommandCode 单账号直连不再显示「账号池 1/1 可用」；本地池即使只启用一个账号仍显示池状态。
- 多个浮层实例并存时 `stop`/`start` 会按「fox-dock overlay + daemon 端口」归一，不再留下看不见的残留窗；不会误杀 ZCode/WorkBuddy 的「小挂件」浮层。
- 浮层默认使用硬件合成；软件渲染只在 `FOX_DOCK_SOFTWARE_RENDER=1` 时启用。
- 透明窗首帧等页面加载完成再显示，并沿用 toolbar 型窗口，避免宿主遮挡判定把浮层当遮挡源。

## 0.1.0-pre.0（未发布）

第一版：从零到「拖到 agent 窗口上就能看到今日消耗」。

### 角色与台词（R12）

- **六个内置角色**：嘎啦嘛 / 大肥鱼 / GPT娘 / kimi娘 / 小克 / 哈基米，610×610 透明立绘；
  立绘从挂件线原样复制，角色默认嘎啦嘛
- **台词**：点击角色、绑定成功、换角色时说话；每个角色一套原台词池
  （换角色说「挑经句」）；随机台词默认 5 分钟一句，可在设置里调 3/5/10 分钟或关掉
- **角色尺寸**：基础 64px（原来 52px 的 emoji 换成 64px 立绘），设置里的
  0.75×/1×/1.25×/1.5× 继续生效
- 拖拽中、面板打开、数字气泡正在显示时不说台词，避免抢话

### 真机修复：最小化窗口把狐狸扔到屏幕外

- 绑定窗口最小化时 Windows 返回 `(-32000,-32000)` 的矩形，原来直接拿去定位，
  狐狸会被摆到看不见的地方（表现为「挂件没反应」）
- 桥改为区分 `minimized` / `offscreen` / `rect-failed`；dock 只在矩形可信时移动，
  最小化期间保留绑定原地等待，窗口还原后继续跟随
- 最小化期间重启挂件也会恢复绑定（只是先不摆位置）

### 从挂件线移植（R11）

- **设置页**（面板「设置」）：大小（0.75/1/1.25/1.5）、跟随间隔（250/500/1000ms）、
  数字卡片开关、每轮消耗气泡与停留秒数、今日预算、额度预警、滚动条宽度、提醒气泡开关；
  改动立即生效并写入 `%LOCALAPPDATA%\fox-dock\settings.json`
- **每轮消耗气泡**：绑定窗口每花完一轮，在狐狸头上冒一次金额（首次读到不冒；
  用「今日累计 + 本轮」指纹识别，两轮同额也能认出来）
- **今日预算 / 额度预警**：跨 agent 汇总人民币（美元与积分不混算）超过预算时提醒；
  同一天同一项只提醒一次
- **滚动条避让**：贴右/下边默认留 17px，不盖住宿主滚动条（可调 0–60）
- **明细搜索**：按适配器名或日期过滤「今日」与最近几天记录
- **关于页**：版本、Electron/平台、pid·端口·运行时长、数据目录、适配器、绑定数、
  最近日志与「复制诊断信息」（不含密钥，路径已脱敏）
- 未移植音效 / 角色 / 桌宠模式 / 余额源，理由见 `docs/dock/MIGRATION.md`

### 启动与生命周期

- `launch/启动 fox-dock.vbs` / `停止 fox-dock.vbs`：双击即可，不闪黑框；失败弹框并留日志
- `fox-dock start` 现在同时拉起后台服务**和浮层**（`--no-overlay` 只起服务），`stop` 一起收掉
- 浮层在 daemon 失联约 12 秒后自己退出，不会在桌面上留一只点不动的狐狸
- 浮层重启后自动恢复上次绑定（窗口还在的话），不用重新拖
- 登录自启也改走 `start`，开机就有狐狸

### 核心

- 常驻服务（`daemon/`）：单实例锁、令牌停止、只监听 127.0.0.1、数据目录 `%LOCALAPPDATA%\fox-dock`
- Win32 桥：常驻 PowerShell 助手，编译一次 C#，之后逐行收命令（snapshot / hit / cursor / rect / ping）；
  命中采样 0.13–0.19ms，200 次连续命中 95ms
- watchdog：异常退出 1s→30s 退避重启；正常停止一起退出；连续 8 次强杀都能拉起且绑定不丢
- 登录启动：启动文件夹 VBS（隐藏窗口），`install/uninstall`
- 浮层（Electron）：透明 + 置顶 + 全窗穿透，只有指针压在狐狸上才可交互

### 交互

- 拖动狐狸 → 松手绑定 → **四分吸附**（与挂件线同款）：落点中心靠近哪条边就贴哪条边，
  中间区域保留原位置；窗口移动/缩放时跟着走
- 拖到空白处松手 = 解绑，狐狸留在原地，不再跟着原来的窗口
- 不再画目标窗口的高亮框：拖到可绑定窗口上时只有狐狸自己描边放大
- 鼠标穿透改为**主动轮询光标**：WorkBuddy 等宿主在前台时也能点/拖狐狸
- 单击狐狸 → 明细面板：当前窗口数字、窗口标题、全部 agent 今日汇总、最近几天、解绑
- 深色模式跟随系统

### 适配器

- 框架：声明式匹配（exe 基名 / 路径片段 / 标题片段 / 窗口类），不加载第三方 JS；
  返回值统一过 `normalizeSnapshot`（单位、币种、百分比、错误）
- `zcode`：读 `~/.zcode/cli/db/db.sqlite`，逐行按价目折算；价目内核与挂件线逐字节一致（`check:sync` 守护）
- `workbuddy`：扫 `~/.workbuddy/projects/**/*.jsonl` 的 `rawUsage.credit`；按请求归轮、按轮首事件归日
- `generic`：能绑定、能跟随，但明确显示「暂不支持计费」，不猜数字
- 对账工具：`verify:zcode` / `verify:workbuddy` 逐日比较金额/积分与 tokens

### 账本

- `ledger.json` 按 (日期, 适配器) 记今日累计；`unit|currency` 分组汇总，元/积分/币种绝不混算
- 保留 30 天；`GET /summary`

### 维护

- `GET /diag.json` + `fox-dock diag --out`：版本/适配器/绑定/账本/更新历史/最近日志，家目录脱敏
- 更新：清单 Ed25519 签名 + 包 sha256 + 逐文件备份 + 失败整批回滚；`update --check/--apply/--history`
- 打包：`npm run pack` 产出 `dist/dock-<version>.tar.gz` 并签名清单
- 测试：121 条（单测 88 + 集成 33）；集成测试串行执行（并行时多个全屏浮层互相遮挡）
- 真机 e2e：可把狐狸拖到真正的 ZCode / WorkBuddy 窗口上；CLI 启停、绑定恢复都有真 Electron 用例

### 修掉的真机问题（2026-10-18）

- 浮层被 Chromium 判为「被遮挡」→ 渲染进程节流，拖拽期间所有请求卡到松手后才返回
- 同理，命中查询改走**主进程 IPC**（渲染层在鼠标手势期间网络会被整体挂起）
- `window.screenX` 在窗口激活/DPI 校正前后会变（实测差 128px）→ 坐标基准改为
  指针事件自己的 `screenX - clientX`，主进程 `getBounds()` 兜底

### 已知限制

- 只支持一块屏（默认光标所在屏）；跨屏拖动不支持（D011）
- GLM 订阅用量按按量价显示（没移植账号套餐判定，D008）
- 更新包签名密钥在本机 `%USERPROFILE%\fox-dock-release-key.pem`，换密钥需重签
