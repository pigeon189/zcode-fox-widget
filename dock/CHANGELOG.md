# fox-dock 变更记录

> 2.0 起按通用桌宠产品线维护（tag `dock-v*`）。接口、数据格式、适配器契约仍可能变。

## 2.0.0-pre.3（未发布——等人工放行）

### 新增

- **权限接管（M5，D036）**：`settings.permission.takeover` 打开后，宿主的权限请求会在宠物权限卡与控制台横幅上等待决策；只有「允许一次 / 拒绝」，永不提供 always-allow；超时或任何失败都 fail-open 交回宿主原生弹窗。高风险命令（`rm -rf`、`git push --force`、`curl | sh` 等 15 类规则）不提供热键允许、「允许一次」不设默认焦点。有 pending 时动态注册 `Ctrl+Alt+Y/N`，清空即注销；桌面通知文案脱敏 ≤60 字、点击聚焦宿主窗口。随包集成插件 `dock/integrations/zcode-plugin/`（只挂 4 个低频钩子）+ 零依赖 `dock/hooks/dock-hook.mjs`。P-2 已真机探针确认（2026-10-25）：stdout `{"continue":true,"decision":"approve"}` = 允许、exit 2 = 拒绝、原生卡片阻塞等待——「允许一次」默认可用，高风险仍无热键允许。
- **自定义 agent 接入公开化（D037）**：`POST /v1/ingest` 的 `permission_request + wait` 现在会真实长轮询等决策（此前只登记/忽略）；新增 `GET /v1/actions`、`POST /v1/actions/:id/resolve`（🔒）与 SSE `action` 事件。
- **猫娘语音库（1.x v1.16.3 迁移）**：内置三套音效——小黄鸭 / 嘀嘟（原「音效1」更名）/ 猫娘（CC0，一声制：按压喵声 + 松手静音，出处见 NOTICE 第 4 条）；支持自定义音效集导入（1～2 个文件、单文件 ≤2MB、mp3/wav/ogg/m4a/aac 魔数校验）、删除与切换。设置页「角色与气泡」新增按压音效卡片，宠物菜单可直接切换。旧挂件 `~/.zcode/whale/sounds/` 自定义集随导入流程一并迁移。
- **首次接入向导（M6）**：检测宿主 → 接入方式 → 完成，一键导入旧挂件数据（含音效集）；可在「关于与诊断」重新打开。
- **增量索引持久化（M6）**：WorkBuddy 会话尾随水位与已解析事件持久化到 `cache/workbuddy-index-v1.json`（schemaVersion + appVersion，版本不符即弃；原子写 + 2s 去抖；单文件 ≤8MB LRU）；「删除缓存后结果不变」有等价性测试守卫。
- **便携包**：`pack-release.mjs --portable` 产出解压即用包，附 Node 22.5+ 运行时检测说明（不静默下载）。
- **桌面悬浮也避让右侧滚动条**：「避让滚动条」此前只在吸附宿主右边时生效；现在桌面悬浮（未吸附）时按屏幕（工作区）右缘留出同样宽度——最大化窗口的纵向滚动条就在屏幕右缘。开关/宽度变化会立即按新缝重新夹取悬浮位置（开启即左移，从开切到关且正停在「右缘−旧缝」上时贴回右缘），不用再拖一次。
- **GLM 赠送池按模型分桶的进度条（D053）**：GLM start plan 的赠送池按模型分开记账（实测 GLM-5.3-Flash 已用尽、GLM-5.3 还剩 0.4%），此前汇总成「总桶 0.2% 剩余」看不出是哪个池子见底。现在额度页厂商卡与顶部额度卡按桶画进度条（名称 + 剩余百分比 + 剩余/总量 + 已用比例条，与 CommandCode 窗口同款），宠物层快览卡在窗口行后追加最多 3 条桶行；汇总百分比保留作参考。桶数据来自日志源 `byModel`，总额不可得的桶不显示、不补 0。

### 修复

- **用量页把「金额不可得」显示成 ¥0.00**：聚合已把价目未收录的模型标成 `amount:null + unavailable`，但 `fmtMoney(null)` 走 `Number(null)=0` 返回 ¥0.00，同一行出现「¥0.00 / 不可得」；CSV 也把 null 写成 0。现在金额/积分格式化把 `null`/空串当缺失显示「—」（真实 0 仍是 ¥0.00），排名与两张明细表同口径，CSV 金额列导出空单元格、JSON 保留 `null`。
- **「已完成」几乎抓不到（D056）**：`done` 只是回合结束后 4 秒的机器状态，`expire` 一过就变「空闲」，所以列表/胶囊/快览卡事后看到的永远是空闲。现在进入 `done` 记 `doneAt`，控制台、胶囊与快览卡在 5 分钟内继续显示「已完成」；新回合开始、出错或等待确认会立即覆盖它。计数、状态筛选与 SSE 摘要同源（`displayStatus`），UI 不再自己按 `status==='done'` 推断。
- **workflow 在跑时父会话显示空闲（D056）**：编排回合已经结束、`dwf_run`/`workflow_run` 还在跑时，父会话按 `parent_session_id` 标成工作中（「已完成」从 workflow 结束时刻起算）；子任务状态继续按根会话合并。
- **工具结束到首字之间闪成空闲（D056）**：库内没有 running 的回合行，长工具结束后到下一次模型请求落库之间会超过 90 秒。现在无钩子时把「最新模型行晚于上一回合结束」的在跑回合宽限到 10 分钟；有钩子时用 `turn_start`/`turn_end` 维护 `turnActive`，`db done` 才清标记，并设 15 分钟上限防止 Stop 丢失后「工作中」永不结束。
- **控制台改设置要等约 1 秒才在宠物层生效**：设置原本靠 2 秒轮询拉取；daemon 改设置时本来就会广播 SSE `state`，现在宠物层收到事件后立即（150ms 内合并）刷新设置，换角色/改大小/隐藏金额即时生效，2 秒轮询只作兜底。
- **快览卡出现滚动条**：卡片锚点用 `offsetHeight`（已被上一次 max-height 压制）预留高度，越压越矮——实测 375px 内容被压到 358px，多出 17px 滚动条。改为按 `scrollHeight + 边框` 预留；最大高度 480 → 560px，CommandCode「余额 + 3 个额度窗口 + 3 条会话」的常规内容一次放得下。异步内容（会话/额度窗口/时段）晚到时不再受「打开后 1.5 秒」限制：只要真的出现滚动条就把卡片上移（只上不下，没溢出不动，轮询不会抽动）；窗口/上下文/会话的垂直间距各收紧 2–4px。
- **最大化 ↔ 窗口化切换后图表约 1 秒才适配**：两张图的高度是按窗口宽度算的 prop，原来只在数据轮询（约 1 秒）时重渲染，刚切换的一瞬仍是旧形状。概览现在监听 `resize`，下一帧更新视口宽度，图表形状与 CSS 媒体查询同步切换（实测 120ms 内 viewBox 已从 90/220 变成 56/148）。
- **任务卡空态紧贴标题行**：任务卡改为纵向 flex，空态（当前没有进行中的会话 / 没有待处理事项 / 一切正常）在剩余空间里垂直居中，并与标题行留 8px。
- **总览今日用量迷你图两侧留白**：窄窗口下 CSS 把图表高度压到 56px，但组件仍按 90px 的 viewBox 绘制，`preserveAspectRatio` 等比缩放后折线缩在中间、左右空出一大截。现在组件与 CSS 统一成 56px（viewBox `0 0 宽度 56`），折线铺满卡片宽度。
- **总览「当前会话」卡排版**：标题与「当前会话 / 工作中」之间留 10px；「查看会话」从独立一行并入上下文进度条那一行（进度条 + 百分比 + 链接）。
- **总览首屏看不到「近 7 天成本 / 额度窗口」**：窗口宽度 ≤1279px 时四张任务卡变两列，空态卡（160px）加 90px 迷你图把两张图顶出首屏——默认 1020×769 窗口实测底部超出 46px。两列模式改为压缩任务卡空态（56px、图标 20px）、任务卡内边距（12px 14px）、今日迷你图（56px）与 7 天柱图（220 → 148），额度窗口/近 7 天成本两卡的自身空态内边距压到 16px、预警条在 `.grid` 里不再叠加额外下边距；默认 960×680 窗口实测「四张卡 + 近 7 天成本 + 额度窗口」全部落在首屏（预警条同屏时底边 677px），1020×769 更宽裕；宽窗口布局不变。
- **徽标紧贴相邻文字**：真正的问题是相邻间距，不是徽标自身尺寸（上一版的 22px/内边距调整已回滚）。`.stat-label` 改为 flex 布局（标签与徽标/来源圆点之间 6px，同时修正「待处理 / 预警」计数未右对齐的问题）、「今日成本」头部的来源圆点同步 6px、侧栏「关于与诊断」与在线状态之间留 8px、厂商表名称列的 id 与类型徽标之间 8 → 28px。全站徽标/来源标签/质量 chip 扫描后没有小于 6px 的相邻间距。
- **统计页两个刷新按钮**：去掉工具条里的「刷新」，统一用页头图标按钮。
- **统计页日期段控件随宿主名长度移动**：左侧「ZCode / WorkBuddy / DeepSeek Harness · 应用用量」占固定 208px（截断 + title），日期段控件位置固定。
- **改显示缩放后角色落到 agent 窗口下方**：浮层窗口与 PowerShell 桥的 DPI 上下文都在启动时固定。150% → 125% 后浮层仍是 2562×1530 @144 DPI（比 2560×1440 的屏幕还高 90px），桥返回的宿主矩形也偏大 1.2 倍，角色被贴到屏幕外的「工作区底部」。现在浮层监听 `display-metrics-changed` / `display-added` / `display-removed`，按新工作区重设窗口；缩放变化时调用 `POST /v1/maintenance/bridge-restart` 重建桥（无令牌 403），完成后让渲染层立刻重读 `/rect`。实测重启端点约 1.3s。
- **吸附后角色无法沉底（底部悬空 17px）**：「避让滚动条」在 1.x 只作用于贴右边（`lib/widget.js` 仅 `hAnchor==='right'` 扣 rightGap），2.0 在底边也扣了一次，开着该设置时角色离宿主窗口底部一段距离。现在底/顶/左边一律贴死，只有右边留滚动条宽度；设置说明与迁移文档同步，旧挂件导入时 `scrollGapPx` → `scrollGap` 正确映射（此前键名不同被静默丢弃）。
- **设置页点控件后整个界面上移（避让滚动条等）**：`.content` 是滚动容器但不是定位祖先，设置页里绝对定位的隐藏控件锚到初始包含块、逃出裁剪，把 document 撑到内容高度；聚焦控件时浏览器把 document 滚下去，标题栏和侧栏被顶出窗口。现在滚动容器同时作为定位祖先（`position: relative`），`ui-check` 增加「document 不得纵向滚动」断言，9 页 × 2 主题 × 3 视口全过。
- **会话成本口径严重虚高（D054）**：会话列表/回合明细原来直接按模型价乘 token，没有剔除预付池——实测一个 1300.1M tokens 的会话显示 ¥317.09，其中 GLM start plan 订阅池占 ¥279.97、CommandCode credit 池占 ¥25.74，真实按量只有 ¥12.31。现在与「今日已用」同一判据链（名字规则 + 官方 Base URL + GLM 订阅修正）：预付池金额记 0、tokens 照算；整段都是预付用量时成本列显示「≈等价市值」并标注不是真实支出，不再出现整列 ¥0.00。
- **换模型 / 峰谷分段计价（D054）**：会话成本与回合成本改为按「模型 + provider + 整点桶」聚合后逐桶计价——换模型后的 token 只按新模型价算，DeepSeek 峰谷/周末档位按每笔实际发生时间取档（旧实现整组按最后一笔时间算，实测差 ~3%）；混合模型回合不再被 `MAX(model_id)` 压成单一模型的价格。
- **重启后成本冻结在旧价目（D054）**：`live-sessions.json` 恢复的累计量在适配器同一 `updatedAt` 时会被丢弃；现在时间戳相等时累计量以适配器为准（实时状态仍用内存），改价目/改口径后空闲会话也能刷新。
- **会话成本列截断 WorkBuddy 积分**：成本列 92 → 112px（详情回合表 96 → 108px），「251.85 积分」不再被裁掉。
- **控制台白屏兜底（D055）**：页面渲染错误由 `ErrorBoundary` 兜成「重新渲染 / 重新加载 / 复制错误」卡片，侧栏与其它页面继续可用；渲染进程崩溃/无响应/主框架加载失败改为 60s 滑动计数 + 0/1/3/10/30s 退避重载（旧实现 10 秒内只重载一次，第二次崩溃就永久白屏），每次崩溃追加一行到 `<数据目录>/console-crash.log`。
- **宠物菜单移除「说一句」**：台词仍由单击角色与随机絮语触发。
- **长台词气泡跑离角色**：台词气泡改为独立确定性定位——首选角色正上方、其次正下方，快览卡打开时把卡片当硬遮挡、换到卡片左右外侧/上下方（候选耗尽前不会压住卡片），并强制整只气泡留在视口内。根因是通用候选打分的 overflow 启发式把「贴右缘夹取」误判成溢出，右下角场景里「正上方」稳输。金额/提醒气泡维持原避让规则。
- **权限卡显示期间整块桌面点不动**：宠物层与工作区等大，权限卡出现时渲染层曾无条件 `setInteractive(true)`，`setIgnoreMouseEvents(false)` 会让卡片显示期间（默认 15s 等待 / broker TTL 30s）所有桌面点击被浮层吞掉。现在 `isOverUI` 纳入 `#perm`，只有指针压在卡片上才接管鼠标，其余区域继续穿透。
- **权限横幅按钮在默认/最小窗口被裁掉**：会话页横幅是单行 flex，760×560 下「拒绝」只剩 11px、默认 960×680 下「允许一次 / 查看全部」出界。横幅与待办行允许换行、按钮组整组落到下一行，三个决策按钮在两个窗口都可达；深色主题预览文字改用 `--text-2`（原 `--text-3` 在 warn 底色上 4.3:1，axe serious）。
- **「允许」热键绕过 allowOnce**：`Ctrl+Alt+Y` 此前只看 risk，`allowOnce` 关闭（分支 B）后仍能把 pending resolve 成 allow；现在与卡片同口径，takeover + allowOnce 都开启且非高风险才注册。
- **控制台权限横幅的「允许一次」不判 takeover**：关闭「接管权限请求」后 broker 里的 pending 还有 TTL（最长约 30s），总览/会话页横幅仍显示并可用「允许一次」。现在与宠物层卡片、权限热键同口径：takeover 与 allowOnce 都开启且非高风险才显示该按钮，关闭接管后横幅只剩「去宿主处理」「拒绝」。
- **权限通知带完整命令**：通知正文此前截取 preview 前 60 字（ingest 只遮密钥/主目录，命令本体完整保留）；现在只写工具名与处理提示，不带 preview，点击仍聚焦宿主窗口。
- **高危权限动作可被本机进程代为放行（终审）**：`GET /v1/actions` 读接口不要令牌就能枚举 pending（含命令预览与 requestId），`resolve` 也不校验调用者身份——拿到 `daemon.lock` 令牌的同用户进程（含被接管的 agent 自己拉起的后台进程）可直接把高危请求 resolve 成 allow，钩子随即向宿主输出 approve、压掉原生确认窗。现在读接口也要令牌；`ActionBroker` 在 daemon 侧拒绝任何高风险动作的 `allow`（含伪造的 `permission_resolved` 事件），只保留「拒绝」与超时 fail-open 回宿主原生弹窗；lock 文件按 0600 写。同用户进程的底层冒充风险与残余边界见 D036 修订。
- **相对写路径带 `..` 也不算越界**：写工具的相对目标此前只要不是绝对路径就跳过 cwd 比较，`..\..\Windows\hosts`、`sub/../../../Windows/hosts` 这类可判定的越界写入被判 normal，卡片照常给「允许一次」。现在相对目标按 cwd 解析后再判，裸相对路径也纳入写目标检查；普通相对路径（`src/a.mjs`、`sub/../src/a.mjs`）仍在 cwd 内不升级。
- **JSON 形态的凭据不脱敏**：钩子用 `JSON.stringify` 序列化 tool_input，`{"token":"…"}`、`{"password": "…"}`、`{"access_token":"…"}` 这类键值对绕过了只认 `=`/`:`/空白的旧规则，值会原样进入权限卡预览并随 pending 落到 `live-sessions.json`。现在 JSON 凭据字段（含被 400 字边界截断的半截值）一并遮蔽，`tokenizer` 这类键名不误伤。
- **长 tool_input 在钩子侧被截到 2000 字**：`PermissionRequest` 上报此前固定 2000 字，超过 2000 字的危险尾命令在 daemon 的 8000 字 `riskPreview` 之前就被切掉。现在按「8000 字符 + 序列化后 15KB」双重预算裁剪（多字节文本按 UTF-8 字节安全截断，不超 ingest 16KB 上限），长前缀不再掩盖尾部命令。
- **接入向导「开机自启」不生效**：向导完成时只把 `autoStart` 写进 settings，从不调用 `/v1/maintenance/autostart`，打开不装 VBS、关掉后下次开机仍自启；现在「完成」前先经该端点安装/移除启动件（D048）。「跳过」不碰自启（首启机器 `autoStart` 默认 true 而启动件未装时，跳过不应安装 VBS）。
- **快览卡分桶行尾列被裁**：按模型分桶的「剩余/总量」尾列固定 62px，`497.58M/500M`、`12345.68M/20000M` 这类真实量级会撑出横向滚动、尾数看不全；尾列改为按内容自适应，标签列可收缩。
- **兜底摆位不再持久化**（迁移 1.x v1.16.6 issue #11 修复）：失焦/最小化落角是瞬时状态，不写回 `floating.rect`；daemon 只记录用户亲手拖出的位置。
- **聚焦宿主第②级回退**：窗口聚焦在「标题含 cwd 目录」与「任意窗口」之间补上「绑定中的该 agent 窗口」优先级。
- **音量「静音」不生效**：`soundVolume=0` 被 `|| 0.5` 回落成 50%——角色页下拉显示「50%」、宠物层也按 50% 播放。现在 0 作为合法值保留（设置页与宠物层两处同修），静音后刷新/轮询也不会弹回 50%。

### 真机修复：最小化窗口把狐狸扔到屏幕外

- 绑定窗口最小化时 Windows 返回 `(-32000,-32000)` 的矩形，原来直接拿去定位，
  狐狸会被摆到看不见的地方（表现为「挂件没反应」）
- 桥改为区分 `minimized` / `offscreen` / `rect-failed`；dock 只在矩形可信时移动，
  最小化期间保留绑定原地等待，窗口还原后继续跟随
- 最小化期间重启挂件也会恢复绑定（只是先不摆位置）

### 启动与生命周期

- `launch/启动 fox-dock.vbs` / `停止 fox-dock.vbs`：双击即可，不闪黑框；失败弹框并留日志
- `fox-dock start` 现在同时拉起后台服务**和浮层**（`--no-overlay` 只起服务），`stop` 一起收掉
- 浮层在 daemon 失联约 12 秒后自己退出，不会在桌面上留一只点不动的狐狸
- 浮层重启后自动恢复上次绑定（窗口还在的话），不用重新拖
- 登录自启也改走 `start`，开机就有狐狸

### 核心

- 常驻服务（`daemon/`）：单实例锁、令牌停止、只监听 127.0.0.1、数据目录 `%LOCALAPPDATA%\fox-dock`
- Win32 桥：常驻 PowerShell 助手，编译一次 C#，之后逐行收命令（snapshot / hit / cursor / rect / ping）；
  命中采样 0.13–0.19ms，200 次连续命中 95ms
- watchdog：异常退出 1s→30s 退避重启；正常停止一起退出；连续 8 次强杀都能拉起且绑定不丢
- 登录启动：启动文件夹 VBS（隐藏窗口），`install/uninstall`
- 浮层（Electron）：透明 + 置顶 + 全窗穿透，只有指针压在狐狸上才可交互

### 交互

- 拖动狐狸 → 松手绑定 → **四分吸附**（与挂件线同款）：落点中心靠近哪条边就贴哪条边，
  中间区域保留原位置；窗口移动/缩放时跟着走
- 拖到空白处松手 = 解绑，狐狸留在原地，不再跟着原来的窗口
- 不再画目标窗口的高亮框：拖到可绑定窗口上时只有狐狸自己描边放大
- 鼠标穿透改为**主动轮询光标**：WorkBuddy 等宿主在前台时也能点/拖狐狸
- 单击狐狸 → 明细面板：当前窗口数字、窗口标题、全部 agent 今日汇总、最近几天、解绑
- 深色模式跟随系统

### 适配器

- 框架：声明式匹配（exe 基名 / 路径片段 / 标题片段 / 窗口类），不加载第三方 JS；
  返回值统一过 `normalizeSnapshot`（单位、币种、百分比、错误）
- `zcode`：读 `~/.zcode/cli/db/db.sqlite`，逐行按价目折算；价目内核与挂件线逐字节一致（`check:sync` 守护）
- `workbuddy`：扫 `~/.workbuddy/projects/**/*.jsonl` 的 `rawUsage.credit`；按请求归轮、按轮首事件归日
- `generic`：能绑定、能跟随，但明确显示「暂不支持计费」，不猜数字
- 对账工具：`verify:zcode` / `verify:workbuddy` 逐日比较金额/积分与 tokens

### 账本

- `ledger.json` 按 (日期, 适配器) 记今日累计；`unit|currency` 分组汇总，元/积分/币种绝不混算
- 保留 30 天；`GET /summary`

### 维护

- `GET /diag.json` + `fox-dock diag --out`：版本/适配器/绑定/账本/更新历史/最近日志，家目录脱敏
- 更新：清单 Ed25519 签名 + 包 sha256 + 逐文件备份 + 失败整批回滚；`update --check/--apply/--history`
- 打包：`npm run pack` 产出 `dist/dock-<version>.tar.gz` 并签名清单
- 测试：121 条（单测 88 + 集成 33）；集成测试串行执行（并行时多个全屏浮层互相遮挡）
- 真机 e2e：可把狐狸拖到真正的 ZCode / WorkBuddy 窗口上；CLI 启停、绑定恢复都有真 Electron 用例

### 修掉的真机问题（2026-10-18）

- 浮层被 Chromium 判为「被遮挡」→ 渲染进程节流，拖拽期间所有请求卡到松手后才返回
- 同理，命中查询改走**主进程 IPC**（渲染层在鼠标手势期间网络会被整体挂起）
- `window.screenX` 在窗口激活/DPI 校正前后会变（实测差 128px）→ 坐标基准改为
  指针事件自己的 `screenX - clientX`，主进程 `getBounds()` 兜底

### 已知限制

- 只支持一块屏（默认光标所在屏）；跨屏拖动不支持（D011）
- GLM 订阅用量按按量价显示（没移植账号套餐判定，D008）
- 更新包签名密钥在本机 `%USERPROFILE%\fox-dock-release-key.pem`，换密钥需重签
