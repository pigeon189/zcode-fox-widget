# fox-dock 变更记录

> 2.0 起按通用桌宠产品线维护（tag `dock-v*`）。接口、数据格式、适配器契约仍可能变。

## 2.0.0-pre.3（未发布——等人工放行）

### 新增

- **权限接管（M5，D036）**：`settings.permission.takeover` 打开后，宿主的权限请求会在宠物权限卡与控制台横幅上等待决策；只有「允许一次 / 拒绝」，永不提供 always-allow；超时或任何失败都 fail-open 交回宿主原生弹窗。高风险命令（`rm -rf`、`git push --force`、`curl | sh` 等 15 类规则）不提供热键允许、「允许一次」不设默认焦点。有 pending 时动态注册 `Ctrl+Alt+Y/N`，清空即注销；桌面通知文案脱敏 ≤60 字、点击聚焦宿主窗口。随包集成插件 `dock/integrations/zcode-plugin/`（只挂 4 个低频钩子）+ 零依赖 `dock/hooks/dock-hook.mjs`。P-2 已真机探针确认（2026-10-25）：stdout `{"continue":true,"decision":"approve"}` = 允许、exit 2 = 拒绝、原生卡片阻塞等待——「允许一次」默认可用，高风险仍无热键允许。
- **自定义 agent 接入公开化（D037）**：`POST /v1/ingest` 的 `permission_request + wait` 现在会真实长轮询等决策（此前只登记/忽略）；新增 `GET /v1/actions`、`POST /v1/actions/:id/resolve`（🔒）与 SSE `action` 事件。
- **猫娘语音库（1.x v1.16.3 迁移）**：内置三套音效——小黄鸭 / 嘀嘟（原「音效1」更名）/ 猫娘（CC0，一声制：按压喵声 + 松手静音，出处见 NOTICE 第 4 条）；支持自定义音效集导入（1～2 个文件、单文件 ≤2MB、mp3/wav/ogg/m4a/aac 魔数校验）、删除与切换。设置页「角色与气泡」新增按压音效卡片，宠物菜单可直接切换。旧挂件 `~/.zcode/whale/sounds/` 自定义集随导入流程一并迁移。
- **首次接入向导（M6）**：检测宿主 → 接入方式 → 完成，一键导入旧挂件数据（含音效集）；可在「关于与诊断」重新打开。
- **增量索引持久化（M6）**：WorkBuddy 会话尾随水位与已解析事件持久化到 `cache/workbuddy-index-v1.json`（schemaVersion + appVersion，版本不符即弃；原子写 + 2s 去抖；单文件 ≤8MB LRU）；「删除缓存后结果不变」有等价性测试守卫。
- **便携包**：`pack-release.mjs --portable` 产出解压即用包，附 Node 22.5+ 运行时检测说明（不静默下载）。

### 修复

- **宠物菜单移除「说一句」**：台词仍由单击角色与随机絮语触发。
- **长台词气泡跑离角色**：台词气泡改为独立确定性定位——永远停在角色正上方、箭头指向角色，只做视口内夹取，允许与快览卡边缘重叠。根因是通用候选打分的 overflow 启发式把「贴右缘夹取」误判成溢出，右下角场景里「正上方」稳输。金额/提醒气泡维持原避让规则。
- **兜底摆位不再持久化**（迁移 1.x v1.16.6 issue #11 修复）：失焦/最小化落角是瞬时状态，不写回 `floating.rect`；daemon 只记录用户亲手拖出的位置。
- **聚焦宿主第②级回退**：窗口聚焦在「标题含 cwd 目录」与「任意窗口」之间补上「绑定中的该 agent 窗口」优先级。

## 2.0.0-pre.2（2026-10-24）

「成本与额度真相层 + 会话实时层」为主体，把四个宿主的数据统一成可信、可追溯、可下钻的
会话与用量；放行前按真机反馈持续修补宠物层落位、状态判定与计价口径。

### 新增

- **火山方舟订阅配额卡**：「额度与余额」新增「火山方舟（Coding/Agent Plan）」卡片——Coding（5 小时/周/月百分比）与 Agent（近一天/周/月用量）分别查询官方接口、分别缓存，一个套餐查询失败不影响另一个；凭据为火山 IAM AK/SK（模型调用的 ark- key 不适用），可在「厂商与密钥」页成对配置（本机加密保存），未配置或查询失败时如实显示不可得原因，不显示虚假满额。
- **火山按量/订阅计费分流**：方舟接入按官方 Base URL 路径区分——/api/coding、/api/plan 为订阅口径（金额记 0、token 照算、标签归「火山 Coding/Agent Plan」），/api/v3 为按量（真金白银、标签归「火山方舟」）；经方舟出网的托管模型（deepseek-v3 等）不再被误算进原厂按量账单。
- **统计页**：按宿主展示累计 Token、峰值单日、最长聊天、连续天数、活动热力图、每日模型趋势、模型占比与工具用量；ZCode 读本地 `model_usage`/`turn_usage`/`tool_usage`，WorkBuddy 读 transcript，dsh 读会话日志，Kimi 只提供套餐额度窗口。
- **会话分页与归档**：会话列表改为每页 25 个根会话 + 「加载更多对话」，按 keyset 游标追加，滚动到底不再一次拉取 200+ 条；新增「当前 / 已归档 / 全部」归档筛选（父会话归档时子会话随父），切换筛选或排序回到第一页。`/v1/sessions` 新增 `archived` 三态、`rootTotal`/`truncated` 与稳定 `nextCursor`。
- **控制台自绘日期控件**：用量与统计的自定义区间改用 `DatePicker`（周一起始月历、方向键/Home/End/PageUp/PageDown/Enter/Esc、min/max 禁用、关闭后焦点回到触发按钮），不再弹出浏览器原生日期面板。
- **按模型换角色**：GLM→嘎啦嘛、DeepSeek→大肥鱼、GPT→GPT娘、Kimi→kimi娘、Claude→小克、Gemini→哈基米；同一模型族连续两拍确认后才切换，避免模型名抖动；宠物菜单与设置页提供开关，手动选角会关闭自动切换。
- **每日积分预算**：除金额预算外新增积分预算 `budgetCredit`（0 = 关闭）；每天、每个阈值只提醒一次，金额与积分各自独立计数。
- **用量明细搜索**：用量下钻支持按模型/厂商/会话等维度名、日期（`2026-10-17`、`10-17`、`10月17日`）和时间（`14:30`）过滤明细；图表、磁贴、合计与导出始终使用完整聚合口径，WorkBuddy/dsh 的无 `aggregateUsage` 退路也一样。
- **厂商覆盖扩展**：新增 17 个模板（Azure OpenAI、AWS Bedrock、Google Vertex AI、Cloudflare Workers AI、Cohere、Perplexity、Replicate、Hugging Face、NVIDIA NIM、SambaNova、Lambda、Nebius、商汤日日新、百川、零一万物 Yi、面壁 MiniCPM、昆仑万维），官方无 API-key 余额接口的模板统一为 `kind:'tokens'`，只报凭据是否配置并用于本机 token 计价。
- **余额构成**：DeepSeek 的赠金与充值余额在额度页分开显示（`balanceSplit`）；任一侧缺失就隐藏该侧，两侧都缺失时整行隐藏，不补 0；存在人工校正时隐藏构成行，避免总额与拆分对不上。
- **会话页**（导航第 2 项，Ctrl+2）：跨 agent 会话列表（状态/标题/模型/路径/回合/Token/成本/耗时/更新）、搜索/状态筛选/排序、父任务与子任务折叠、键盘导航、25 个根会话一页 + 「加载更多对话」；右侧详情含概览/回合/工具/上下文四个标签与「跳转到宿主窗口」。
- **会话实时层**：`shared/session-model.mjs` 统一 Session；`LiveTracker` 合并适配器轮询与事件注入；SSE 新增 `session` / `sessions`；`GET /v1/sessions`、`GET /v1/sessions/:key`、`GET /v1/sessions/:key/context`、`POST /v1/sessions/:key/focus`。
- **可信度标签 provenance**：每个金额/Token/百分比带 `exact|estimated|unavailable` + `origin` + `source/asOf`；UI 四标签「官方接口 / 本地日志 / 估算 / 不可得」（缺失不补 0）。快照、上下文、统计、账本、会话、导出都有。
- **事件注入协议 v1**：`POST /v1/ingest`（16KB、逐字段校验、令牌桶、自定义 agent 上限 8）；旧的 `/v1/events` 映射到同一归约器。
- **用量深化**：`GET /v1/usage/breakdown`（按 Agent/模型/厂商/工具/会话 × 今日/7 天/30 天/自定义，环比与 30s 缓存）；用量页统计磁贴、StackedColumnChart、排名榜、明细表与 CSV/JSON 导出（BOM、CRLF、公式注入防护）；本月预测与样本不足空态。
- **统计/额度**：统计页自定义范围与来源标签；额度页新增「卡片｜矩阵」视图（余额、5 小时/周/月窗、重置于、来源）。
- **总览任务化**：今日成本（环比 + 7 日 Sparkline）、当前会话（状态/运行时长/上下文）、待处理、预警四块卡；保留 7 天成本、额度窗口、厂商余额与全部 Agent 今日。
- **宠物状态层**：胶囊工作旋转弧、等待/出错/完成色点、`ZCode · 工作中` 文案、活跃会话角标（9+）；快览卡新增最近 3 个会话（点击直达会话详情）。状态只由胶囊表达，角色本体不再叠加状态徽标。
- **设置「会话与权限」**：显示会话状态、接管权限请求（默认关）、等待时长、通知策略、允许/拒绝热键、本地事件接入、接入地址、会话保留天数；schema 3（v1/v2 无损升级）。
- **关于与诊断**：接入诊断表（数据源/实时通道/最后事件/正常·未接入·延迟）与「复制集成目录路径」。
- **ZCode 聚焦桥**：`bridge.ps1 focus <hwnd>`（前台失败回落 FlashWindowEx），只允许聚焦已发现的宿主窗口。

### 变更

- **失焦兜底提速与落角可选**：宿主失前台/被完全覆盖的兜底防抖 3 秒 → 0.5 秒；兜底位直接贴住工作区角落（浮层窗口与工作区精确重合，仅任务栏自动隐藏时留 1 DIP 不可见缝防压滑出热区）；兜底角落新增「失焦兜底位置」设置（右下/左下/右上/左上，默认右下，迁移 1.x defaultCorner），落在角落时角色面向屏幕内侧，回前台自动恢复吸附与常规朝向；没有历史位置时首帧也从所选角落出现。
- **设置页全局热键逐项标注**：三个热键拆成独立设置行（显示或隐藏角色 / 打开控制台 / 隐藏金额），各自标明作用与格式，不再三个输入框散列在一行里。
- **退出与开机自启的文案区分**：托盘与宠物菜单的退出项标注「（本次退出）」，设置页「开机自启」说明退出只是本次、不影响本开关；控制台关闭按钮仍是收进后台。语义与行为未变，本次补齐文案与防回归测试。
- **换角色 180ms 淡入**：切换角色时新角色以 180ms 淡入登场（零延迟，图片立即切换）；系统开启「减少动态效果」时自动关闭。
- **价目快照更新（2026-10-24）**：收录当日发布的 Kimi K3.1 Pro 及高速版——输入 ¥13/¥26、输出 ¥68/¥136、缓存命中 ¥1.30、缓存写 ¥13/¥26 每百万 token；同步收录 MiniMax M3.1-Flash、GLM-5.3-FlashX-Legal、OpenAI Rosalind 研究系计价。DeepSeek、GLM、Claude、Qwen、MiMo 官方现价复核无变化；Gemini 官方页本次不可达，经 LiteLLM 注册表交叉验证沿用上次快照。

### 核心

- 常驻服务（`daemon/`）：单实例锁、令牌停止、只监听 127.0.0.1、数据目录 `%LOCALAPPDATA%\fox-dock`
- Win32 桥：常驻 PowerShell 助手，编译一次 C#，之后逐行收命令（snapshot / hit / cursor / rect / ping）；
  命中采样 0.13–0.19ms，200 次连续命中 95ms
- watchdog：异常退出 1s→30s 退避重启；正常停止一起退出；连续 8 次强杀都能拉起且绑定不丢
- 登录启动：启动文件夹 VBS（隐藏窗口），`install/uninstall`
- 浮层（Electron）：透明 + 置顶 + 全窗穿透，只有指针压在狐狸上才可交互

### 修掉的真机问题（2026-10-18）

- 浮层被 Chromium 判为「被遮挡」→ 渲染进程节流，拖拽期间所有请求卡到松手后才返回
- 同理，命中查询改走**主进程 IPC**（渲染层在鼠标手势期间网络会被整体挂起）
- `window.screenX` 在窗口激活/DPI 校正前后会变（实测差 128px）→ 坐标基准改为
  指针事件自己的 `screenX - clientX`，主进程 `getBounds()` 兜底

### 已知限制

- 只支持一块屏（默认光标所在屏）；跨屏拖动不支持（D011）
- GLM 订阅用量按按量价显示（没移植账号套餐判定，D008）
- 更新包签名密钥在本机 `%USERPROFILE%\fox-dock-release-key.pem`，换密钥需重签
